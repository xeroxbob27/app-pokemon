# Pokédex

Aplicativo mobile desenvolvido em React Native (Expo) que consome a [PokeAPI](https://pokeapi.co/) para permitir a busca e o gerenciamento de uma lista de pokemons favoritos. O usuário pode adicionar um pokemon pelo nome ou número, visualizar seu perfil com tipos e estatísticas base, e remover itens da lista, com os dados persistidos localmente via AsyncStorage.
